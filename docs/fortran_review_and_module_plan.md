## PSD 的实际约定

头部顺序为 `ROADTYPE, q0, qr, q1, h0, H`，本附件取值：

```text
ROADTYPE = BD_thick_rubber_block_for_mixlub
q0 = 10 m^-1
qr = 10 m^-1
q1 = 1e9 m^-1
h0 = 1（原始头部值）
H = 1（原始头部值）
```

随后两列为 `log10(q)` 与 `log10(C(q))`，不是线性 q/C，也不是自然对数。源码约定 q 为波矢大小，单位 m⁻¹，C 为二维各向同性高度 PSD，单位 m⁴；不得擅自把 q 当作 cycles/m 再引入或删去 2π。

采用该约定时：

\[
h_{\rm rms}^2=2\pi\int_{q_0}^{q_1}qC(q)\,dq,\qquad
\langle|\nabla h|^2\rangle=2\pi\int_{q_0}^{q_1}q^3C(q)\,dq.
\]

`READPROCESS`（6985 起）读取和处理谱。`INPUT` 2313 行令 `ispline=1`，`spline` 在 27143 行直接返回，`splint` 在 27198–27199 行使用线性项。因此**默认在 log–log 坐标中分段线性插值，等价于每段幂律**；不能仅凭例程名认为它做三次样条。

这还不是全部预处理设置：`IN_npolyCq.npolyab.npolyE` 决定是否多项式平滑，`IN.mathematical` 第 18 项 `scaleC` 决定谱幅值缩放。这两个文件尚缺，因此当前不能确认作者该算例是否实际启用了平滑或缩放。原程序还存在额外谱处理路径，完整复现需要整个输入集。

数值 PSD 路径会重新积分 RMS，并将 `h0` 更新为所得值（约 7363–7380 行）。**不能把头部 `h0=1` 解释为该表面的真实 RMS 等于 1 m**；也不能由头部 `H=1` 替代整条数值谱。

### 接触面积

粗糙刚体—弹性半空间路径采用 \(E^*=E/(1-\nu^2)\)。若未来两侧都可变形，应在材料层先计算有效模量，而不是重复套用泊松比修正。

定义谱矩 \(I(q)=\int_{q_0}^{q}q'^3C(q')\,dq'\)，标准非黏附弹性路径为

\[
G(q)=\frac\pi4(E^*)^2 I(q),\qquad
a(q,p)=\frac{A}{A_0}=\operatorname{erf}\!\left(\frac{p}{2\sqrt{G(q)}}\right).
\]

源码还输出命名为 `aexact`/`aexact1` 的经验修正拟合。这个变量名不代表严格精确解；新程序必须区分模型版本，不能一边用标准面积、一边无说明地混入另一面积拟合的导数。

### 平均间隙与微观分布

分离量不是只由面积公式得到。其积分核使用 `UcorrectionFactor`（记为 γ），并存在不同能量积分方法；γ 及方法需从完整控制文件确认，不先填入猜测值作为研究参数。

其中一个路径的积分核为

\[
F(z)=\int_z^\infty[\gamma+3(1-\gamma)\operatorname{erf}^2(x)]\frac{e^{-x^2}}x\,dx.
\]

γ=1 时退化为指数积分 \(E_1(z^2)/2\)，可以作为独立验证特例。

`hWithoutAdhesionMagnification1` 先计算 \(a(\zeta)\)、\(\bar u(\zeta)\) 和未解析粗糙度，然后由

\[
u_1=\bar u+\frac{d\bar u}{d\mu}\frac{a}{da/d\mu},\quad \mu=\ln\zeta
\]

构造随尺度刚离开接触区域的特征间隙，并以 \(-da/d\mu\) 为权重组合中心位于 ±u₁ 的高斯核。核方差还包含 `afact` 修正：

\[
\sigma_u^2=\left[\frac{\texttt{afact}}{u_1^2}+\frac1{h_{\rm rms}^2(\zeta)}\right]^{-1}.
\]

这是带模型修正及离散截断的分布近似。源码中有面积阈值、`u1min`、间隙积分上限等，不能把它们隐含进一条通用的“Persson 公式”。数组 `Probabilityrms` 含积分权重，不能当作密度值直接绘图。源码也对 \(\int uP(u)du\) 与平均间隙做检查；新程序应报告该偏差，不通过强行改矩来隐藏它。

## 模块接口：沿用用户的职责划分

### 模块 1：输入与配置

输出 `problem` 与 `options`。建议显式分开：

- `problem.roughness`：原始 PSD、谱约定、单位、q0/qr/q1、预处理及来源；保留原数据。
- `problem.material`：材料参数与有效模量来源；第一阶段为弹性、非黏附。
- `problem.operating`：压力/间隙数据库的目标范围；未来加入载荷与速度工况。
- 几何与流体参数保留后续接口，但生成干接触表不应强制提供无用的流体参数。
- `options`：面积/能量/分布模型版本、尺度和压力网格、积分容差、截断、插值与越界策略。

首先支持本次原始 PSD 格式；普通两列格式需由配置显式给出线性/对数与单位。不能靠数值范围静默猜测。不要自动平滑、改单位、补尾或覆盖原附件。

### 模块 2：Persson 接触与数据库

| 函数职责 | 输出与约束 |
| --- | --- |
| `persson_area` | 给定尺度与名义干接触压力的 a；明确标准/经验修正版本 |
| `persson_mean_gap` | h(p_c)，并在单调有效区间构造 p_c(h) |
| `persson_gap_pdf` | 零间隙接触概率质量与连续正间隙密度，保留归一化诊断 |
| `build_contact_table` | 缓存压力/尺度/间隙响应，记录输入与模型/网格元数据 |
| `evaluate_contact` | 查询 p_c(h)、a(h)、P_+(s\|h)，检查有效范围和插值误差 |

Python 可使用对应的 `.py` 文件；MATLAB 可保持原先 `.m` 文件名。先采用普通函数和清晰数据结构，不要求面向对象。

这里建议约定 h 为平均界面间隙，s 为局部微观间隙，a 为实际接触面积比，p_c 为按名义面积平均的干接触承载压力。接触斑块内平均压力 p_c/a 是另一个量；不能混用，后续才可明确使用 p_c+p_f 的名义承载平衡。

建议明确将 \(P_+(s\mid h)\) 定义为**已知 s>0 的条件密度**。于是完整分布写为

\[
P(ds\mid h)=a(h)\,\delta_0(ds)+[1-a(h)]P_+(s\mid h)\,ds,\quad s>0,
\]

\[
\int_0^\infty P_+(s\mid h)ds=1,\qquad
h=[1-a(h)]\int_0^\infty sP_+(s\mid h)ds.
\]

若原程序给的是按总名义面积加权的连续密度，其积分应为 1−a，需要除以 1−a 后才得到这里定义的 P₊。a=1 时不存在正间隙条件分布，应单独处理。这个记号约定需在接口中固定，并与用户研究中的 P₊ 定义对齐。

验收顺序：PSD 格式/单位及谱矩 → 面积的低压/高压极限和单调性 → h(p_c) 单调性及反查误差 → 零间隙质量与连续密度积分、第一矩 → 网格/截断收敛 → 相同输入及选项下与 Fortran 输出对照。已有 PSD 独立检查，其他验证状态由实际测试与结果记录说明；不能把 Python 内部检查等同于 Fortran 对照验证。
