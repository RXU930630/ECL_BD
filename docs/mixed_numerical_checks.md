# 正向混合摩擦与数值核查（rc5）

在 main.py 开启 `RUN_MIXED_FRICTION=True`，关闭独立泄漏、宏观干接触、干摩擦及拟合任务。`COMPUTE_PRESSURE_FLOW`、`COMPUTE_SHEAR_FLOW` 可以都为 False：混合润滑始终在内部使用两类流动，两个 COMPUTE 开关只负责独立任务。`shear_flow` 分组的独立速度不控制混合润滑；请在 `mixed_friction.lower_wall_velocities_m_s` 填写速度，单位 m/s。

正向计算必须填写已知或明确假定的界面剪切强度。与原版比较时，两版材料、谱、几何、载荷、速度、黏度、粗糙侧、供油边界、所比较物体和剪切强度必须一致。`tau=1 MPa` 可以作为公开指定的基准常数，不是已拟合的实验属性。

## 数值核查

`parameters.py` 的 `NUMERICS['mixed_friction']['numerical_checks']` 控制额外计算。默认从实际速度列表中选择低、中、高三个代表点，分别执行：

1. **空间网格**：单元数从 N 增至 2N−1，复用完全相同的接触和输运模型，以检查空间离散。
2. **接触/输运表及谱求积**：接触和输运表点数增至 2N−1，n_q 加倍，pdf_log_step 减半。保持主空间网格不变；该联合检查不能区分是哪一张表或谱积分导致变化。
3. **截断区间**：仅对零表压边界的无限圆柱，将半区间加倍，并增加单元数以维持相近的网格间距。接触/输运模型保持相同。有限胶块的轴向长度、滑动方向长度及曲面半径均不改变，不执行扩大区间的检查。

主结果始终是用户输入的网格和几何所对应的解；辅助结果不会自动替换主结果，也不会自动改写 parameters.py。需要加密主结果时，修改输入设置、使用新输出目录后重跑。

比较量包括真实接触面积/轴向宽度、最小平均间隙、最大流体压力、流体承载比例、固体摩擦、流体滑动剪切、流体压力驱动剪切和总摩擦系数。带符号的流体分项可以助推，不逐项取绝对值。

默认判断为 `|check−baseline| <= 绝对容限 + 0.02*max(|check|,|baseline|)`。摩擦绝对容限为 1e-4，流体承载比例绝对容限为 0.001；面积绝对容限按“tau=1MPa 时贡献1e-4的摩擦系数”换算，只是诊断尺度，不改变输入 tau。膜厚绝对容限为 1e-12 m，压力为 1e-6 Pa。

- `passed_at_selected_cases`：已执行的代表点满足设定容限；不等于全速度范围收敛，更不等于物理模型验证通过。
- `needs_attention`：变化超限、主远场边缘压力偏高，或辅助求解失败。主结果仍保存供检查。
- `incomplete`：资源上限或关闭某项检查导致核查不全。达到上限不会被当成通过。
- `not_checked`：未开启额外核查。旧参数文件缺少此分组时，按未开启处理，保持兼容。

`maximum_cells` 是辅助计算的内存/耗时上限；求解器单元数硬上限为2049。表点数上限也会检查。核查失败会记录具体原因，绝不通过增加非物理导流地板或修改空化/接触模型来强行通过。

边缘压力很小不能替代区间敏感性检查。有限胶块没有可任意扩大的一段实际材料，固定边界内的网格核查也不能证明“边缘储液压力”等边界条件符合实验。

## 输出

- `mixed_results.xlsx`：主计算状态、全部速度的摩擦/承载/面积/膜厚、数值核查差异和各项执行情况。
- `mixed_cases.csv`：全部主结果；新增四个带 `lower_resisting_*_coefficient` 的固体/流体分量列。
- `mixed_profile_*.csv`：空间分布，包括 pc、pf、h、A/A0、theta、壁面牵引；`mixed_transport_table.csv` 包含内部剪切流动因子和摩擦因子。
- `mixed_numerical_checks.json` / `.csv`：核查状态、容限、参数和逐项变化。未执行比较时不生成差异 CSV。
- `numerical_checks/mesh`、`tables_and_spectral_quadrature`、`domain`：已完成的辅助正向解，与主结果分开。

主状态 `workflow_status=complete` 表示非线性方程求解完成；精度状态另看 `numerical_validation.status`。空化和摩擦的物理闭合在 rc5 中保持 rc4 的形式，未以接近原版为目标修改它们。

## 拟合诊断

拟合仍是一个非负常数 tau，不增加截距或更改优化目标。新增按载荷分别估计 tau 的诊断表、整体/分载荷残差、逐点接触灵敏度、拟合杠杆和逐点隐含 tau（仅对实际参与拟合的点）。它们帮助检查常数 tau 假设，不自动将模型改成载荷依赖。

`fit_results.xlsx` 新增“各载荷独立诊断”。默认在相对训练 RMSE 超过0.1、至少有两个参与点的不同载荷组的 tau 比超过2、或已提供测量不确定度时约化卡方超过4时突出提示。这些是可调整的筛查阈值，不是通用的物理验证标准。可在 `shear_strength_fit.diagnostics` 设置 `maximum_relative_rmse`、`maximum_tau_ratio_across_loads`、`maximum_reduced_chi_square`。

旧保存结果可继续拟合，但会明确标记未进行新的数值核查。正向核查未完成/未通过时，拟合数值仍输出为待核查的条件估计；统计标准误不包含模型误差。强度较小或全膜润滑点对 tau 不敏感，调 tau 无法修复这些点的流体摩擦失配。
