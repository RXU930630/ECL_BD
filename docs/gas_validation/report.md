# 500/5000气体计算验证记录

基于包含 `3caf351` 的当前工作副本，保留原液体模型，在现有导流积分、输运表与空间守恒求解器中加入二次导流律。使用方法见 [gas_leakage.md](../gas_leakage.md)。

## 历史输入复算

这里使用用户后来提供的历史输入，而非最初提出的E=1.8 MPa工况：E=2.07 MPa、ν=0.5、γ=0.4，液体黏度0.001 Pa·s；PSD为历史四点文件，q1=9.8e7 m⁻¹，积分对数步长0.005。沿用原程序的坐标映射、小坐标端入口、spc=0.8平台与线性导流表插值。入口取历史输出最后一行414370 Pa表压，出口0；R=9.525 mm，横向宽度2πR。气体参数为25°C、平均分子速率471 m/s、黏度1.82e-5 Pa·s，环境与参考绝对压力均为100000 Pa。

| 计算 | 总流量（mm³/h） | 含义 |
| --- | ---: | --- |
| 500液体 | 0.01786790 | 液体总体积流量 |
| 500附加diffusive估算 | 3.015797 | 用液体解换算的气体参考体积流量 |
| 500附加ballistic估算 | 33.85556 | 用液体等效间隙换算的气体参考体积流量 |
| 5000独立ballistic | 32.69029 | 独立二次均质化与压力求解后的气体参考体积流量 |

5000分子流率为2.2059628673e14 s⁻¹；参考体积流量为9.0806365626e-12 m³/s。气体体积均对应1 bar绝对压力、25°C，不是除以入口压力得到的“每bar”系数。5000空间网格为3569点，流量网格变化约9.24e-7。两种ballistic结果不同，是因为二次均质化一般不等于三次均质化结果的2/3次幂，压力与局部卸载也重新求解。

历史Fortran输出的液体流量约0.01782527 mm³/h，辅助diffusive与ballistic列分别折算为3.00857与33.80235 mm³/h。500复算保留此前约0.24%的差异，没有因增加气体功能改变液体结果。

## 原Fortran二次导流循环

参考源文件为 `AI.ContactMechanics.14.09.2026.f90`，SHA256为 `99d3b2e2c47a663ffe8b65bbdb7415db5eeebb434debd0ef404006600e861854`。使用GNU Fortran 14.2.0；驱动逐字提取原 `Sealing3gas` 的迭代循环，保留原来的 `u²-u_end²` 截断项。Python使用非负的局部u²导流律。

本检查使用由原Fortran独立生成的2048点和4096点PDF；接触压力98867.55781 Pa、有效弹性模量2.4 MPa、对数步长0.01，采用此前仓库PSD。这是同一物理状态的两种PDF分辨率，与上表历史输入不同。

| PDF点数 | Fortran K2（m²） | Python独立K2（m²） | 相对差异 |
| --- | ---: | ---: | ---: |
| 2048 | 2.2650546349e-18 | 2.2639992233e-18 | −0.04660% |
| 4096 | 2.2650546348e-18 | 2.2639992233e-18 | −0.04660% |

原循环12000至24000次迭代结果变化约6e-12相对值；相同PDF下用非负u²求根与原截断循环的差异约0.000288%。详细数值、输入输出及驱动哈希见 [closure_reference.json](closure_reference.json)，实际驱动见 [ballistic_reference.f90](ballistic_reference.f90)。复算脚本为 `scripts/verify_ballistic_reference.py`，参数说明可用 `--help` 查看。

`python -m unittest discover -s tests`：79项通过。覆盖原液体回归、500估算公式、5000均匀狭缝及两相解析解、二次与三次均质化的差别、零/反向流量、阻断、气体参考状态及速度缩放、黏度独立性、两种模式工作流与独立源文件入口。另已检查开启绘图后的完整5000输出。
