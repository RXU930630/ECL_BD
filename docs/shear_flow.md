# 模块4：单侧粗糙的剪切流动与固定接触输运

已实现恒黏度、无滑移、各向同性条件下的单侧粗糙剪切流动因子，以及固定接触状态中压力驱动与运动带液的守恒组合。原压力驱动泄漏与ballistic气体路径继续保留。

这里使用原Fortran Sealing3中的Persson插值公式，不把它称为直接PDF推导的剪切有效介质。压力导流仍使用现有PDF有效介质模型。摩擦因子、载荷分担、宏观变形与膜厚联立、非牛顿、温度场及空化仍待后续模块完成。

## 参数与入口

main.py增加独立开关：

```python
COMPUTE_SHEAR_FLOW = True
```

其默认值为False，保留原有日常运行行为。打开后会自动计算所需接触与压力导流数据库，即使COMPUTE_PRESSURE_FLOW=False。可以关闭RUN_LEAKAGE，仅计算剪切因子及均匀状态流量表；该入口不要求开启RUN_CONTACT。

parameters.py的CASE中增加：

```python
'shear_flow': {
    'model': 'persson_interpolation',
    'rough_surface': 'lower',          # lower / upper，另一侧光滑
    'lower_wall_velocity_m_s': 0.0,
    'upper_wall_velocity_m_s': 0.01,
    'pressure_gradient_pa_m': 0.0,
    'pressure_floor_pa': 0.0,
},
```

两侧速度均沿流向+x定义，允许负值。lower/upper是膜厚方向z=0与z=h，不是入口和出口。当前只读取所选侧对应的同一份PSD；没有自动生成第二表面的粗糙度。

pressure_gradient_pa_m仅用于剪切表中每个均匀接触状态的流量分解，不代替空间问题的压力边界。空间解仍使用入口、出口压力。

若同时开启RUN_LEAKAGE并给出非零壁面速度，还需：

```python
# CASE['leakage']内
'coupling': 'fixed_contact',
'conductance_model': 'effective_medium',
'compute_equivalent_gas': False,
```

首版剪切输运不与局部卸载耦合。已有Navier滑移仍能用于压力流动；非零Navier滑移与新剪切插值的组合会明确报错。ballistic气体、双侧粗糙及运动临界通道组合未启用，不会静默退回其他模型。原气体辅助估算仅适用于压力驱动的无滑移液体，因此运动输运时关闭。

## 定义、符号与极限

设h为平均间隙，r为PSD积分得到的RMS高度，hc为接触面积达到共用渗流阈值时的平均间隙。各向同性下：

```
L_s = r phi_s = h/[1+2h max(h-hc,0)/(3r²)]
q = -K/(12 eta) dp/dx
    + (U0+U1)h/2
    + sign*(U1-U0)L_s/2
```

q为每单位横向宽度的体积流量，单位m²/s；K为现有压力导流系数，单位m³。sign在下壁粗糙时为−1，上壁粗糙时为+1。phi_s输出为非负幅值，另列signed_shear_flow_factor以标明归属符号。两壁速度对应的系数之和为h，满足整体速度平移的通量变换。

两侧同速U时q_motion=Uh。光滑极限r=0时剪切修正为零，恢复平行板带液；大间隙时L_s趋于3r²/(2h)。h不大于hc时L_s=h，静止粗糙壁面/运动光滑壁面的插值带液项为零；粗糙壁面运动时保留液体随纹理输运的项。压力导流已经阻断时，表中的非零运动源项不等于已经求得贯通泄漏，空间运动求解会拒绝零导流区域。

hc由真实渗流阈值计算，不是spc平台对应间隙。spc仅继续影响压力导流表，不能将其误当作剪切插值的物理阈值。

原程序使用固定的h−hc<1e-10 m切换。此实现改为max(h−hc,0)，避免给物理插值引入固定长度的起始区；差异在参考验证中单独记录，不作为用户日常参数。

## 固定接触空间求解

在r(x)=12eta/K(x)和s(x)=q_motion(x)已给定时：

```
q = [p_in-p_out + integral(r s dx)] / integral(r dx)
dp/dx = r(s-q)
```

使用逐级加密的守恒积分，不沿用静止壁面求解器中的单调压力假设。支持零压差带液、压力与带液抵消的零净流量、反向净流量及内部压力极值。压力剖面和流量都进行网格检查。

pressure_floor_pa是运动空间解的有效性检查下限，单位Pa表压。默认0；低于此下限会明确失败，不裁剪负压，也不假装已经求得空化解。只有具备相应物理依据时才调整下限；它不替代质量守恒空化模型。

运动空间解要求内部各点有可定义的有限间隙和正压力导流；内部开口区或零导流区会报错。Hertz端点的零接触压力不作为有限间隙输出；内部仍以接触数据库计算。此阶段不更新接触承载或膜厚。

## 本次完整示例

完整测试集102项通过。另使用仓库PSD运行111个接触压力节点及绘图流程：E=3 MPa、ν=0.5、eta=0.1 Pa·s，方环接触长度1 mm、横向宽度10 mm、参考接触压力0.1 MPa，固定接触，下壁速度0、上壁0.01 m/s，出口表压0。两种归属共用同一接触与压力导流数据库，RMS=1.409922364 μm，hc=0.091773508 μm。

| 入口表压（Pa） | 下壁粗糙、上壁光滑（mm³/h） | 上壁粗糙、下壁光滑（mm³/h） |
| --- | ---: | ---: |
| 0 | 0.811011 | 97.785381 |
| 10000 | 0.811239 | 97.785609 |
| 50000 | 0.812154 | 97.786524 |

该差异来自同一插值模型对静止粗糙面和运动粗糙面的不同带液预测，不是实验泄漏率。空间方程的最大归一化残差低于2e-16；这只说明数值守恒，不包含插值模型误差。零速度开关回归保持原压力驱动结果不变。
