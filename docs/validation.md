## 仍存在的分布限制

间隙 PDF 是原程序启发的反射高斯近似，倍率方向使用有限体积离散，尚未与原程序同参数输出比较。

- 示例中分布解析第一矩相对于独立平均间隙的偏差最高约 **6.35%**。
- 最大未解析非接触概率约 **2.94×10⁻⁴**（按名义面积计）；保留为独立诊断，没有转为接触质量或重归一化。
- 极小间隙的窄峰使点值密度的梯形积分可能完全失真。区间概率使用解析高斯 CDF 差计算；`gap_bins` 还提供区间平均密度。
- 面积和平均间隙的检查通过，不意味着 PDF 的第一矩等式严格满足。分布暂不应作为后续流动因子或摩擦积分的已验证输入。
