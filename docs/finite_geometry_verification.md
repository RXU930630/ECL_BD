# 有限曲面几何与拟合入口验证（0.2.0rc2）

本次修改沿用既有Persson接触、半空间弹性、守恒空化与强耦合方程。有限表面不是有限厚度弹性体；本次未增加背衬约束、预应力或轴向端部模型。

## 新增行为

- `finite_cylindrical_pad`根据实际圆弧曲率、流向长度和轴向长度生成表面范围，不要求估计数值半宽。
- 支持投影长度和圆弧长度；不将有限表面自动延伸到远场。
- 轴向长度统一用于载荷和摩擦总力换算。拟合CSV的总力逐行覆盖默认载荷，计算内部仍使用N/m。
- 有限模式不套用无限圆柱的远场边缘压力阈值；储液压力仍在两端单元面施加，载荷、几何、通量守恒与空化条件仍须满足。
- 速度扫描可从已收敛的相邻速度继续，保留耦合压力/饱和度初值；遇到失败时在实际起点和目标之间插入中间驱动状态，不修改最终方程。

## 三载荷、九速度检查

采用仓库PSD，E=1.8MPa、ν=0.5、η=1Pa·s；成形半径0.17m、轴向0.10m、投影流向长度0.03m。物理表面范围固定为±15mm，257单元，厚度0.02m仅记录。两端储液表压0，连续供液、无滑移、等温、单侧粗糙。

总力40、100、160N，对应400、1000、1600N/m。每档载荷计算1、3、10、30、100、300、1000、3000、10000µm/s，共27个工况。

检查使用刚建立的1201级设置接触表和163节点输运表，在三档载荷间共用这套材料/界面本构表，独立重算各载荷的干接触和全部耦合状态。通过完整`run_project(..., run_shear_strength_fit=True)`任务入口运行；验证脚本只替换本构表的重复建立过程，没有替换耦合求解器、法向方程或拟合算法。

27个最终工况全部收敛，最终版本的最大残差：

| 检查 | 最大值 |
| --- | ---: |
| 总载荷相对误差 | 1.20e-9 |
| 几何归一化残差 | 3.41e-9 |
| 所有单元面通量极差/最大通量 | 7.23e-7 |
| `max(p*(1-theta))`，Pa | 0 |

确认物理边界表每个工况记录±15mm、两端储液表压0和守恒通量；输出几何、摩擦分项与诊断文件可读。这里检查的是给定离散模型的收敛与守恒，不是实测摩擦验证，也不代表所有工况已完成空间、谱积分和输运查表的独立加密研究。

## 已知强度回收

使用上述真实耦合解的面积与流体贡献，构造合成摩擦系数`mu=mu_fluid+650000*(A_real/F_N)`；未使用用户实测摩擦数据。由保存的27个正向状态拟合，回收`650000.0000000001 Pa`。固体接触敏感性不足的高速点依现有阈值排除，仍保留预测。该检查验证载荷换算、面积归一化、流体/固体分项、结果复用与线性反演的衔接。

## 交付

原0.2.0rc1快照不变。rc2纯净包通过显式清单构建，仅含运行源码、必要输入、空白实验模板与用户说明；本报告和上述验证输出不放入运行包。`--preset silicone_cylinder`预填此次几何、材料、黏度和拟合入口，但不含实测数据。正式构建命令：

```bash
python scripts/build_local_package.py --preset silicone_cylinder --output /path/to/ECL_BD-0.2.0rc2-silicone-trial.zip
```

仍为候选试运行版本，真实界面剪切强度须由用户本地实验拟合与后续独立工况验证。
